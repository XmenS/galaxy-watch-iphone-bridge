# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, give specific feedback, accept that maintainers will sometimes say no.

Report unacceptable behavior to `conduct@galaxyhealthbridge.dev`. Reports are confidential. The steering committee responds within 7 days.
